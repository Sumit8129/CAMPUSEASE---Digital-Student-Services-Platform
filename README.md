# CampusEase 🎓
A centralized student services platform built with Flask, SQLAlchemy, Flask-Login, and Bootstrap 5.

## Features
- User Authentication & Role-Based Access (Admin/Student)
- Campus Notices with Global Search
- Study Materials Hub with Semester & Subject Filtering
- Upcoming Events & Workshops Management
- Career Opportunities (Internships, Jobs, Hackathons)
- Secure Profile Management & Password Reset
